# 30 ejercicios en React

Conversión de los 30 ejercicios de consola en C# (Braulio Ricardo Alvarez Gonzaga) a una aplicación web con React.

- Menú dinámico con categorías y favoritos
- Buscador en vivo (Ctrl+K)
- Resultados en tiempo real, modo claro/oscuro, ejercicio al azar

No necesita instalación: es un único `index.html` que carga React desde cdnjs.

## Ver en local
Abre `index.html` en el navegador.

## Publicar con GitHub Pages
1. Sube `index.html` y `README.md` a un repositorio.
2. En *Settings → Pages*, elige la rama `main` y la carpeta `/ (root)`.
3. Tu sitio quedará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
